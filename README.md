## 🛠️ How to Run Any Program

You need a C compiler such as GCC, TDM-GCC or MinGW.

```bash
gcc filename.c -o filename
./filename          # Linux / macOS
filename.exe        # Windows
```

Programs that use `math.h` need `-lm` on Linux/macOS:

```bash
gcc filename.c -o filename -lm
```
