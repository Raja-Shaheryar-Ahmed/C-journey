## 🛠️ Requirements

- A C compiler such as GCC, TDM-GCC, or MinGW.

## 🚀 How to Run

```bash
gcc filename.c -o filename
./filename          # Linux / macOS
filename.exe        # Windows
```

- Programs that use `math.h` (such as Lab 3's quadratic equation) need `-lm` on Linux/macOS.
- A few files use a capital `.C` extension (for example `Task_06.C`). On Linux/macOS, compile them as C with:
```bash
  gcc -x c Task_06.C -o Task_06
```

## ➕ Adding a New Lab

1. Create a folder named `Programming Fundamental Lab N`.
2. Add the `.c` files and a `README.md` for that lab.
3. Add a row to the Lab Index table above.
